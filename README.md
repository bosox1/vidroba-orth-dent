# Запис на відробку — кафедра ортопедичної стоматології ІФНМУ

Студенти: `/`  ·  Кафедра: `/admin.html`

Два окремі списки: **Стоматологічний факультет ІФНМУ (2–5 курс)** і **Фаховий медичний коледж ІФНМУ (2–3 курс)**.
Відробка щопонеділка о 17:00 на кафедрі. Поля: ПІБ, курс, група, номер теми, дата пропуску, поважна/неповажна причина.

## Деплой на Netlify
1. Push у GitHub → Netlify: Add new site → Import from Git.
2. Environment variables: `ADMIN_PASSWORD` (обовʼязково). Опційно `TIME`, `PLACE`, `RESET_HOUR` (за замовч. 19).
3. Після зміни змінних — Deploys → Trigger deploy.

## Нотатки
- Записи живуть у Netlify Blobs; після понеділка 19:00 (Київ) запис іде на наступний тиждень, старе стирається автоматично.
- Логотип — `public/logo.svg` (спрощена копія), заміни на офіційний файл із тією ж назвою.
- Кольори — змінні на початку `public/style.css`.
